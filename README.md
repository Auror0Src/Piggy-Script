# Piggy-Script
Advanced piggy script [Beta] Alot of features like item giver and item user are unfinished.

## How to run
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Auror0Src/Piggy-Script/refs/heads/main/PiggyStableObf.lua"))()
```

# Features

## Exploits
- Remove Piggy
- Dex Explorer
- Place Finder

## Player Stuff
- BRING BACK GLITCHES
- Walkspeed
- Sprint Walkspeed
- Crouch Walkspeed
- Jump Height
- Fov [Normal = 70, Sprint = 90]
- Infinity Jump
- Noclip
- Force Head colission [For CFCs]

## Item Giver (Unfinished)
- Get Item
- Works with exploits that dont support fire click detector by only teleporting you

## Item user
- use items from anywhere

## Visuals
- Destroy UI
- Item Esp
- Show item names
- Piggy Esp
- Player Esp
- includes the item they have
